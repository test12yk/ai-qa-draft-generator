# 이슈 초안 (예시 출력)

> `python src/generate_issue_draft.py --input examples/sample_bug_report.md` 실행 시 생성되는 결과물의 예시입니다.

## 제목
[Android] 출금 확인 다이얼로그 연속 탭 시 출금 요청 중복 전송 (잔액 이중 차감)

## 발생 환경
- 플랫폼: Android
- 앱 버전: v4.12.0
- 기기: Pixel 8 (Android 14)
- 네트워크: 3G 시뮬레이션 환경에서 재현율 상승

## 재현 절차
1. 출금 화면에서 출금 신청 진행
2. 확인 다이얼로그 노출 시 "확인" 버튼을 빠르게 두 번 연속 탭
3. 잔액 및 출금 내역 확인

## 기대 결과
"확인" 버튼 탭 시 출금 요청은 1건만 서버로 전송되어야 한다.

## 실제 결과
출금 요청이 2건 전송되어 계정 잔액이 의도한 것보다 더 많이 차감됨. 서버 응답은 두 건 모두 200 OK.

## 재현율
10회 중 6회 (네트워크 지연 환경에서 재현율 상승)

## 제안 우선순위
**Critical (제안값, QA 검토 필요)** — 사용자 자산(잔액) 이중 차감으로 이어지는 결제/자금 관련 이슈이므로 최우선 처리가 필요해 보입니다. 다만 실제 심각도 판단과 핫픽스 여부는 담당 QA/PM의 검토가 필요합니다.
