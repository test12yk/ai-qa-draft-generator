# 기능 요구사항: 출금(Withdrawal) 한도 알림 기능 추가

## 배경
사용자가 일일 출금 한도의 90%를 초과하면, 출금 화면 상단에 경고 배너를 노출한다.

## 요구사항
1. 사용자의 24시간 누적 출금액이 일일 한도의 90% 이상이 되면 경고 배너를 표시한다.
2. 배너 문구: "일일 출금 한도의 90%를 사용했습니다. 남은 한도: {remaining}"
3. 한도를 100% 초과하면 출금 버튼을 비활성화하고, 사유를 안내하는 다이얼로그를 노출한다.
4. 자정(사용자 로컬 타임존 기준) 기준으로 누적 출금액이 초기화된다.
5. KYC 등급에 따라 일일 한도가 다르며(Lv.1 / Lv.2 / Lv.3), 등급 변경 시 한도도 즉시 갱신되어야 한다.
6. 해당 기능은 Android / iOS / Web 전 플랫폼에 동일하게 적용된다.
